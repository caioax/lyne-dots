# pt-BR glossary

Terms the Portuguese (Brasil) translation keeps the same everywhere.

## Style

- Address the user as "você".
- Buttons and actions in the infinitive ("Escolher foto"); descriptions as
  sentences or imperatives ("Escolha…", "Você pode…").
- Sentence case: only the first word capitalized (no Title Case).
- `…` for ellipsis; numbers as 1.234,5 (I18n.number does it).
- Gender-neutral wording ("Boas-vindas ao lyne-dots", not "Bem-vindo").
- Proper names stay as they are: Hyprland, Zen Browser, NVIDIA, Wi-Fi,
  Bluetooth, and key names (Super, Ctrl, Shift, Alt, Caps Lock, Print).
